# Local fonts

Bricolage Grotesque (display) and Manrope (body), variable weights 400–800, Latin WOFF2 subsets downloaded from Google Fonts. The fonts are loaded only where used; the cinematic typography is scoped to the home and the ad notice.

Both fonts are distributed under the SIL Open Font License 1.1; their license files are included here.
